# LotoQuant

Plataforma de análise estatística, fechamentos combinatórios, cálculo de Valor Esperado (EV+) e monitoramento pós-sorteio para loterias.

## Estrutura do Projeto
- `/backend` — API FastAPI, motor estatístico vetorizado (NumPy/SciPy), auditoria Qui-Quadrado, cálculo EV+/Kelly e sincronização multi-fonte.
- `/frontend` — Interface React + Vite + Tailwind CSS com painel de análise, fechamentos, simulador de banca e caderno pós-sorteio.
